# AI News Intelligence System

## Project Overview

The AI News Intelligence System is a Natural Language Processing (NLP) project developed as part of the Applied AI & Robotics program at Houston Community College.

The system analyzes news articles, extracts relevant information, classifies content into categories, and generates concise summaries using Artificial Intelligence techniques.

---

## Features

- News article classification
- Automatic text summarization
- Topic categorization
- Text preprocessing and cleaning
- NLP data analysis
- AI-powered language understanding
