# Object Detection and Segmentation

## Project Overview

This project demonstrates the use of modern computer vision techniques to detect and segment objects in real-world images.

The system applies YOLO11 for object detection and segmentation to identify objects, generate bounding boxes, and create pixel-level masks.

## Objectives

- Detect multiple objects in images
- Generate bounding boxes and confidence scores
- Perform instance segmentation
- Visualize detection and segmentation results
- Explore real-world computer vision applications

## Technologies Used

- Python
- YOLO11
- Ultralytics
- OpenCV
- NumPy
- Matplotlib
- Google Colab

## Applications

- Autonomous vehicles
- Parking lot monitoring
- Security systems
- Traffic analysis
- Retail analytics
- Smart city applications

## Dataset

The project uses sample and custom images for object detection and segmentation.

Large public datasets and pretrained model files are not stored in this repository.

## How to Run

1. Open the notebook in Google Colab.
2. Install the required libraries.
3. Upload or select an image.
4. Run the detection and segmentation cells.
5. Review the generated bounding boxes and masks.
